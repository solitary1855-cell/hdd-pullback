# HDD 回拖力計算

水平導向鑽掘（HDD）管線回拖力計算工具，網頁版。

## 功能
- **HDPE 管**：依 ASTM F1962 計算 A、B、C、D 各點張力，檢核安全回拖強度（SPS）。
- **鋼管**：依 PRCI 法（Huey et al., 1996）分段計算，曲線段採三點樑模型；檢核拉應力、彎曲應力、外壓環向應力及組合應力。
- 力單位 kN／tf 切換，外觀亮／暗／系統切換。
- 穿越剖面張力圖、灌水壓艙比較、鑽機回拖能力建議。
- 完整計算過程（代入數值），可展開／收合。
- 案例儲存於瀏覽器、匯出／匯入 .json 案例檔。
- 匯出 Word（.docx）計算書。

## 使用限制
本工具供初步設計與鑽機選用參考。HDPE 容許拉應力請依 PPI Handbook 或 ASTM F1962 現行版次確認；鋼管營運期應力需另行檢核；正式計算書請以標準原文核對。
