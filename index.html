    計算過程

    計算過程以 kN、m、MPa 表示，數值隨輸入即時更新。點各步驟標題可單獨收合。

    HDPE（ASTM F1962）：A 為管材入孔端、D 為鑽機端。 TA = eμaα·μa·wa·(L₁+L₂+L₃+L₄)； TB = eμbα[TA + μb|wb|L₂ + wb·H − μa·wa·L₂·eμaα]； TC = TB + μb|wb|L₃ − eμbα(μa·wa·L₃·eμaα)； TD = eμbβ[TC + μb|wb|L₄ − wb·H − eμbα(μa·wa·L₄·eμaα)]； ΔT = ΔP·(π/8)·(Dh² − D²)，加於 B、C、D 點。wb 為淨浮力（向上為正）。SPS = σa·πD²·(1/DR − 1/DR²)。

    鋼管（PRCI 法）：線形分為 A 側直線段、凹彎、水平段、凸彎、D 側直線段，計算管材完全入孔時的張力。 直線段 T₂ = T₁ + μb|W·cosθ|·L + π·D·L·τ + W·Δz； 曲線段 T₂ = T₁ + 2μb·N + π·D·L·τ + W·Δz， N = |T·h − W·cosθ·Y| / X，h = R(1 − cos(φ/2))，j = √(EI/T)，U = L/j， X = L/4 − (j/2)·tanh(U/2)，Y = L²/8 − j²·(1 − sech(U/2))；T 取段內平均並迭代。 W 為有效重量（向下為正）= 管重 + 被覆 + 管內水重 − 泥漿浮力。 應力檢核：拉應力 ≤ 0.9 SMYS；彎曲應力 fb = ED/(2R)，容許值依 D/t 分級；外壓環向應力 ≤ Fhc/1.5；拉＋彎與拉＋彎＋環向組合檢核。

    本工具供初步設計與鑽機選用參考。1 tf = 9.80665 kN。HDPE 容許拉應力請依 PPI Handbook 或 F1962 現行版次、載重時間與溫度修正確認；鋼管的營運期應力需另行檢核；正式計算書請以標準原文核對。
